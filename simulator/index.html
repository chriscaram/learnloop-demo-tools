What the simulator is told

Everything the simulator is told — the scenario, the random seed and the start date, and for a staged scenario the stage — is sealed into this fingerprint. Any change to any of them, however small, gives a completely different fingerprint. The agent is never given this. At the end of the demo we open the envelope and check that it still matches.

What is this code? A digital fingerprint (SHA-256) calculated from the complete scenario. The same scenario always produces the same code; changing a single number produces a completely different one. The code cannot be turned back into the scenario, so showing it reveals nothing — but it proves later that the scenario was not changed after the agent's findings appeared.

Publishing matters for later: LearnLoop's "Preview reset" restores the app's state from main, so main should hold the final state, and an earlier stage does not need a deploy in the middle of the demo.

Until a case is loaded and read, do not use its part of LearnLoop yourself (the cart and the checkout before stage 2, the Help page before stage 3): your own visits today would be the only recent visits the agent sees on those pages.
